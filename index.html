Project 01 — Commodity Momentum Foundry

85-factor momentum library for commodity futures

Factor specifications, benchmark mapping against classic alpha libraries, and a complete single-factor case study.

  • Specs — F01–F85 with Chinese/English names, math symbols and formulas; grouped into time-series, cross-sectional and strategy-level families.
  • Benchmark study — four-level correspondence to WorldQuant 101 and GTJA 191 alphas; about 30% of factors rely on futures-only inputs (open interest, term structure, warehouse receipts, cross-market linkage) and have no equity-market counterpart.
  • Case study F34 (TRIX) — triple-exponential-smoothing momentum, 81 contracts, 1-day forward-return framework, train / val / test split.
  • Supporting docs — reference handbook (notation, data structure, MAD standardisation) and four literature reviews.

Project 02 — Market Regime Recognition

Six-state regime identification for commodity futures

Built as nowcast, not forecast: direction is largely unpredictable (signal half-life ≈ 12h), while volatility and regime are identifiable. Positioned for risk control and discipline rather than timing alpha.

  • Core signal — signal = sign(R) × min(E/eff, 1): direction times trend-efficiency saturation, compressed into [−1, +1]. Hull MA smoothing.
  • Five timeframes — 15min / 30min / 60min / 2h / 4h, each with separately calibrated (win, eff) pairs; the five converge, and 60min serves as the primary signal.
  • Probabilistic framework — five-dimensional feature vector → hard anomaly gate (gap / volatility burst / limit-lock / liquidity) → generative posterior over six states → HMM forward filtering with grey-zone detection via normalised entropy.
  • Interactive visualisation — K-line charts with regime colour bands and state statistics; red for long, green for short (domestic futures convention).
